# tile-market-api

Symfony API-only backend skeleton for tile market services.

## Stack
- PHP 8.3+
- Symfony 7.4 (skeleton-style minimal setup)
- PostgreSQL
- Docker & docker-compose (php-fpm, nginx, postgres, manticore)

## Quick start
```bash
make install
```
