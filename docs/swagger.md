## 📖 Interactive API Documentation (Swagger / OpenAPI)

After the project launch (`make install` or `make up`) interactive Swagger UI documentation and the OpenAPI specification are available at the following addresses:

- **Swagger UI:** [http://localhost:8080/api/v1/doc](http://localhost:8080/api/v1/doc) (или [http://localhost:8080/api/doc](http://localhost:8080/api/doc))
- **OpenAPI JSON Spec:** [http://localhost:8080/api/v1/doc.json](http://localhost:8080/api/v1/doc.json)
